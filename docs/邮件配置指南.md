# Spring Boot 邮件服务配置指南

## 一、QQ 邮箱配置步骤（推荐）

### 步骤 1：开启 SMTP 服务

1. 登录 QQ 邮箱网页版：https://mail.qq.com
2. 点击顶部 **"设置"** → **"账户"** 选项卡
3. 找到 **"POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务"**
4. 开启 **"IMAP/SMTP服务"**
   - 需要发送短信验证
   - 验证成功后，系统会生成一个 **16位授权码**
   - ⚠️ **重要：授权码只显示一次，请务必保存！**

### 步骤 2：修改 application-local.yml

```yaml
spring:
  mail:
    host: smtp.qq.com       # QQ邮箱SMTP服务器
    port: 587               # STARTTLS端口
    username: 123456789@qq.com    # 你的QQ邮箱
    password: xxxxxxxxxxxyyyyyy   # 16位授权码（不是QQ密码！）
    default-encoding: UTF-8
    protocol: smtp
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
          ssl:
            enable: true
```

### 步骤 3：测试邮件发送

运行测试类：

```bash
# Maven 命令行
./mvnw test -Dtest=OfferMailToolTest

# 或者在 IDE 中直接运行 OfferMailToolTest.java
```

## 三、163/126 邮箱配置示例

```yaml
spring:
  mail:
    host: smtp.163.com
    port: 465
    username: yourname@163.com
    password: 你的授权码        # 163邮箱也需要授权码
    properties:
      mail:
        smtp:
          auth: true
          ssl:
            enable: true      # 163通常用SSL
```

```yaml
spring:
  mail:
    host: smtp.gmail.com
    port: 587
    username: yourname@gmail.com
    password: xxxx xxxx xxxx xxxx   # 16位应用密码（非Gmail密码）

      mail:
        smtp:
          auth: true

            enable: true
```

> 1. 开启两步验证

> 3. 使用应用密码替换配置中的 password

## 五、常见问题排查

### ❌ 错误：535 Error: authentication failed

**原因**：使用了邮箱登录密码，而非授权码

**解决**：
- QQ/163 邮箱必须使用授权码
- 在邮箱设置中重新生成授权码

---

### ❌ 错误：Could not connect to SMTP host

**原因**：网络连接问题或端口被防火墙拦截

**解决**：
1. 检查网络连接：`ping smtp.qq.com`
2. 尝试更换端口（587 换成 465）
3. 关闭 VPN/代理重试
4. 公司内网可能需要联系网管开放端口

---

### ❌ 错误：Mail server connection failed

**原因**：SSL/TLS 配置不正确

**解决**：
```yaml
# 端口 465 使用 SSL
properties:
  mail:
    smtp:
      ssl:
        enable: true

# 端口 587 使用 STARTTLS  
properties:
  mail:
    smtp:
      starttls:
        enable: true
```

---

### ❌ 邮件发送成功但收件人收不到

**排查步骤**：
1. 检查收件人邮箱地址是否正确
2. 查看收件箱垃圾箱
3. 尝试发送给自己的另一个邮箱测试
4. 检查邮件内容是否被识别为垃圾邮件

---

## 六、如何获取各类邮箱授权码

### QQ邮箱
1. 设置 → 账户 → 开启 SMTP 服务
2. 发短信验证后自动显示

### 163/126邮箱
1. 设置 → POP3/SMTP/IMAP
2. 开启客户端授权码
3. 扫码或短信验证后查看

### Gmail
1. 账户 → 安全性 → 两步验证（先开启）
2. 搜索 "应用密码"
3. 选择 "邮件" → 生成 16 位密码

## 七、测试邮件发送的多种方式

### 方式 1：运行单元测试
```bash
./mvnw test -Dtest=OfferMailToolTest#testSendOfferEmail
```

### 方式 2：使用 API 接口
创建一个测试 Controller：

```java
@RestController
@RequestMapping("/test")
public class TestController {
    
    @Autowired
    private OfferMailTool offerMailTool;
    
    @GetMapping("/send-offer")
    public String sendOffer(@RequestParam String email) {
        return offerMailTool.sendOfferEmail(
            email, 
            "测试候选人", 
            "Java工程师", 
            "技术部",
            "2026-04-01",
            "25",
            "上海"
        );
    }
}
```

访问：http://localhost:8123/api/test/send-offer?email=xxx@qq.com

### 方式 3：AI 助手调用
在对话中直接说：
> "给张三（zhangsan@qq.com）发送Offer邮件，职位是高级Java工程师，年薪35万，4月1日入职"

## 九、配置检查清单

发送邮件前，请确认：

- [ ] 邮箱 SMTP 服务已开启
- [ ] 授权码/密码正确（不是登录密码）
- [ ] 邮箱地址填写完整（包含@后缀）
- [ ] 端口与 SSL/STARTTLS 配置匹配
- [ ] 收件人邮箱地址正确
- [ ] 网络可以访问 SMTP 服务器

---

如有其他问题，请查看控制台错误日志或联系邮箱客服。
